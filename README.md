# 我们的回忆馆 💗

一个可以发给女朋友的简约回忆网站：奶油粉的底色、细线爱心、八段错落排布的回忆，点开能看到照片和悄悄话，还有一封可以拆开的信、一个「未完待续」的小心愿区，以及右上角可以开关的八音盒音乐。没有卡通角色，整体尽量干净、留白。

整个网站是**纯静态、无外部依赖**的：不需要服务器、不用登录、不会上传照片，双击 `index.html` 就能看。照片只从本地 `photos/` 文件夹读取。

---

## 1. 先看一眼

双击 `index.html`（推荐 Chrome / Edge / Safari）。

- 开场页点「打开我们的回忆」进入。
- 右上角「音乐」可以开关背景音乐（浏览器实时合成的八音盒，不需要音频文件）。
- 八张卡片都可以点开；点开后左右方向键 / 按钮可以翻上一段、下一段。
- 信封可以拆开，里面是一封写好的信。

> 电脑上直接打开、手机上打开链接，效果都适配过。

---

## 2. 换成你们的名字和日期

用 VS Code 或记事本打开 `index.html`，拉到文件最下面 `<script>` 的开头，找到：

```js
const CONFIG = {
  herName: "宝宝",
  myName: "我",
  since: "",
  ...
```

| 字段 | 说明 |
| --- | --- |
| `herName` | 女朋友的昵称，会出现在开场标题、信、页脚里 |
| `myName` | 你的称呼，会出现在信的落款、页脚里 |
| `since` | 在一起的日期，例如 `"2024-05-20"`。填了之后首屏会显示「在一起第 N 天」；留空就显示「未完待续」 |

改完保存，刷新页面即可。

> 用 Windows 记事本改中文时，请「另存为」并选择 **UTF-8** 编码，不然可能会乱码。用 VS Code 最省心。

## 3. 放入照片（最重要）

把照片放进 `photos/` 文件夹，按下面的编号命名即可，**不需要改代码**：

| 编号 | 对应回忆 | 第一张 | 第二张 | 第三张… |
| --- | --- | --- | --- | --- |
| 01 | 第一次约会 | `photos/01.jpg` | `photos/01-2.jpg` | `photos/01-3.jpg` |
| 02 | 一起看电影 | `photos/02.jpg` | `photos/02-2.jpg` | `photos/02-3.jpg` |
| 03 | 一起吃麦当劳 | `photos/03.jpg` | `photos/03-2.jpg` | `photos/03-3.jpg` |
| 04 | 因为你爱上螺蛳粉 | `photos/04.jpg` | `photos/04-2.jpg` | `photos/04-3.jpg` |
| 05 | 宝宝送我的小蛋糕 | `photos/05.jpg` | `photos/05-2.jpg` | `photos/05-3.jpg` |
| 06 | 女朋友送的生日礼物才是最好的 | `photos/06.jpg` | `photos/06-2.jpg` | `photos/06-3.jpg` |
| 07 | 一起吃吃吃 | `photos/07.jpg` | `photos/07-2.jpg` | `photos/07-3.jpg` |
| 08 | 我女朋友最可爱 | `photos/08.jpg` | `photos/08-2.jpg` | `photos/08-3.jpg` |

规则：

- 支持 `.jpg` / `.jpeg` / `.png` / `.webp`，每段回忆最多 5 张。
- **第一张**（`01.jpg`）会变成卡片封面；点开卡片后能看到这一段的全部照片，带缩略图和左右切换。
- 扩展名建议用小写（上传到网页后区分大小写）。
- 照片比例随意：卡片封面会自动裁切，点开后的弹窗会完整显示。
- iPhone 的 `.heic` 浏览器不能直接显示，请先导出/转换成 `.jpg`。
- 没有照片也完全能看：会显示简约线稿图标和一句小情话，不会有破图。加照片后刷新即可。

如果你给照片起了别的名字，也可以改每条回忆里的 `photos: "photos/01"`，改成你的路径即可（不要带扩展名）。

## 4. 发给女朋友：发布成链接（推荐）

直接把文件夹发过去，手机上下载、解压、找 `index.html` 比较麻烦。更推荐发布成一个网址，微信里点开就能看。

### 方案 A：Netlify Drop（最快，拖拽即可）

1. 打开 <https://app.netlify.com/drop>
2. 把整个 `our-memories` 文件夹（或 `给宝宝的回忆馆.zip`）拖进页面。
3. 等几十秒，会得到一个 `https://xxxx.netlify.app` 的链接。
4. 按页面提示登录/认领站点（免费账号就够用，免费额度对这个小站完全足够）。
5. 把链接发给女朋友。

以后想更新照片，重新拖一次文件夹，或在 Netlify 后台重新部署即可。

### 方案 B：GitHub Pages

1. 在 GitHub 新建一个仓库（Public 即可）。
2. 把 `index.html`、`README.md`、`photos/` 一起上传到仓库根目录。
3. 仓库 **Settings → Pages → Build and deployment**：
   - Source 选 `Deploy from a branch`
   - Branch 选 `main`，目录选 `/ (root)`，保存。
4. 等 1～2 分钟，链接是 `https://你的用户名.github.io/仓库名/`。

### 方案 C：Vercel

1. 把文件夹推到 GitHub，或安装 Vercel CLI。
2. 在 Vercel 里 Import 这个仓库，Framework Preset 选 **Other**，直接 Deploy。
3. 得到 `https://xxxx.vercel.app`。

### 方案 D：直接发压缩包

`给宝宝的回忆馆.zip` 可以直接发微信/QQ。对方解压后双击 `index.html` 能看，但手机端体验不如链接，建议作为备用。

> 发布前最好自己用手机打开链接走一遍：开场、点卡片、翻照片、拆信、音乐开关。
> 站点是公开的，拿到链接的人都能看；不要放太私密的照片。

## 5. 还可以改什么

所有文案都在 `index.html` 底部的 `CONFIG` 里：

- `memories[]`：每一段回忆的标题、副标题、小标签、线稿图标、文案、情话、照片编号。
- `letter`：信的开头、三段正文、可选的 P.S.、落款。
- `wishes`：结尾「还想和你一起做的事」的小标签。
- `loveLines`：点「戳我一下」时随机出现的情话。
- `since`：在一起的天数。

进阶：卡片在桌面端的 `x` / `y` / `w` / `r` 控制错落位置、宽度和倾斜角度；一般不用动。想加第 9 段回忆，复制一段 `{ ... }` 改内容即可，再给它一个不重叠的 `x` / `y` 位置；中心数字会自动变成 09。需要的话可以让我来加。

配色集中在 `:root` 的 CSS 变量里（`--rose`、`--rose-deep`、`--bg` 等），想换主题色改那里即可。

## 6. 小提示

- **音乐**：右上角「音乐」开关。用的是浏览器实时合成的八音盒版《小星星》，没有版权音频文件，离线也能响。部分浏览器要求先点击页面才允许播放，所以进入网站时点一下「打开我们的回忆」就正好。
- **没有外部请求**：不加载任何第三方字体、图片、统计脚本；照片是你自己放进 `photos/` 的。断网也能打开。
- **控制台里的 404**：页面会自动按 `01.jpg`、`02.jpg`…… 的顺序找照片；没有照片时会尝试几个扩展名，所以开发者工具里看到 `ERR_FILE_NOT_FOUND` 是正常的，不影响页面。加了照片后它们会变成 200。
- **浏览器**：建议用 Safari / Chrome / Edge；微信内置浏览器一般也能打开，但正式发之前最好在手机上试一遍。
- **想让我帮你放照片**：把照片发到对话里，告诉我哪张对应哪段回忆，我可以直接帮你排好并重新打包。
